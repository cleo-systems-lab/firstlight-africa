# FIRSTLIGHT

The published files of FIRSTLIGHT, a passport-aware African tourism opportunity desk by Cleo Systems.

**Live:** https://cleo-systems-lab.github.io/firstlight-africa/

- Planning intelligence only. Every signal carries its source, the time it was checked and the time it must be rechecked. Always confirm with the issuing authority and the carrier before travel.
- One static page: HTML, CSS, JavaScript and JSON, readable as they are. It loads nothing from any other origin, sets no cookies and runs no analytics.
- Your passport lens, saves and watches stay in your own browser; "Clear this device" removes them.

This repository holds the build that is served, nothing else.
